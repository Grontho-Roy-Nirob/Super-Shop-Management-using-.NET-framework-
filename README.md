# 🛒 Super Shop Management System

A desktop-based **Smart Retail Management System** developed using C# and .NET Framework (Windows Forms) with a relational SQL database. The application is designed to manage daily retail shop operations such as inventory, sales, products, and employee activities in a structured and efficient way.

## 📌 Project Overview

The system provides separate interfaces for **Admin** and **Salesman**, with role-based access control to ensure secure and organized workflows.

Administrators can manage products, inventory, users, and overall business activities, while salesmen can perform sales-related operations through their dedicated interface.
